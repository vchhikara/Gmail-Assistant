# Code of Conduct

## Our pledge

We want this project to be a welcoming space for everyone who contributes or uses it, regardless of age, background, disability, ethnicity, gender identity, experience level, nationality, appearance, race, religion or sexual identity.

## Expected behavior

- Be respectful and patient, especially with newcomers.
- Give and accept feedback on the work with good faith.
- Assume the best of others and ask when something is unclear.
- Keep discussion on topic and useful to the project.

## Unacceptable behavior

- Harassment, insults, personal attacks or discriminatory language.
- Sexualized language or unwanted attention.
- Publishing someone's private information without permission.
- Trolling or sustained disruption of discussions.
- Any conduct that would be inappropriate in a professional setting.

## Scope

This code applies in all project spaces: issues, pull requests, discussions and any place where someone represents the project.

## Enforcement

The maintainer may edit or remove comments, close or lock threads, and block people who break this code. To report a problem, open a GitHub issue, or contact the maintainer [@vchhikara](https://github.com/vchhikara) through their GitHub profile if you prefer privacy. Reports are handled confidentially, and reporters are not penalized for good-faith reports.
